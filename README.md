# API Voyage

Projet PHP MySQL — API du site voyage.

## Install

- XAMPP, MySQL ON
- `importer_bdd.bat`
- `config/db.php` si besoin

## Lancer

`demarrer_api.bat` → `http://127.0.0.1:8080/info.php`

`regions.php`, `destinations.php`, `users.php` pour afficher en local.

Avec Apache : `.htaccess` → `/regions` etc.

## API

regions, destinations, users, comments, contact, favorites en JSON.

`index.php?r=regions` marche aussi sur le port 8080.
